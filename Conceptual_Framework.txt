Conceptual Framework of the Study

This study adopts the Input-Process-Output (IPO) Model as its conceptual framework. The IPO model illustrates the flow of data and activities within APPOINTLIST: A Web-Based Registrar Appointment Scheduling System for Ilocos Sur Polytechnic State College – Tagudin Campus. The framework demonstrates how user information, appointment requests, and document requests are collected, processed, and transformed into meaningful outputs that improve the efficiency, accessibility, and organization of the Registrar Office's services.

INPUT
The Input consists of the following data required by the system:

1. Student Information
   - Student ID
   - Name
   - Course
   - Year Level
   - Contact Number

2. User Login Credentials
   - Username and password used for authentication and access control within the system.

3. Appointment Request
   - Purpose of Visit
   - Preferred Date and Time

4. Document Request
   - Type and purpose of the requested document to be processed by the Registrar Office.

5. Registrar Office Personnel Information
   - Staff details responsible for managing and processing appointments and document requests.

6. Available Appointment Schedules
   - Predefined time slots and dates available for student appointment booking.

7. SMS Notification Details
   - Mobile number and message content used for sending SMS notifications to students regarding their appointment and document request status.

These inputs serve as the primary data required for the system to manage appointments and document requests accurately and efficiently.

PROCESS
The Process involves the implementation of the APPOINTLIST system, which includes the following activities:

1. User Registration and Authentication
   - Students and registrar personnel register their accounts and log in securely to access system features.

2. Appointment Scheduling
   - Students select their preferred date, time, and purpose of visit to schedule an appointment with the Registrar Office.

3. Appointment Validation
   - The system checks the availability of the requested schedule and validates the appointment details before confirmation.

4. Submission and Processing of Document Requests
   - Students submit document requests, which are then received and processed by the Registrar Office personnel.

5. Approval or Decline of Appointment Requests
   - The Registrar Office reviews appointment requests and either approves or declines them based on availability and policy.

6. Updating the Status of Appointments and Document Requests
   - The system updates the current status of each appointment and document request (e.g., pending, processing, ready for release, completed).

7. Management of Available Appointment Schedules
   - Registrar personnel manage and configure available time slots for appointment booking.

8. Storage and Maintenance of Records in a Centralized Database
   - All student information, appointments, and document requests are stored securely in a centralized database for easy retrieval and record-keeping.

9. Automatic Generation of SMS Notifications
   - The system automatically sends SMS notifications to students when their requested documents are ready for release.

10. Report Generation
    - The system generates reports including pending documents, processing documents, ready-for-release documents, completed documents, and student records for monitoring and decision-making purposes.

These processes ensure an organized, reliable, and efficient management of registrar transactions while supporting both scheduled appointments and walk-in services.

OUTPUT
The Output consists of the following results produced by the system:

1. Confirmed Appointments
   - Successfully validated and approved appointment schedules for students.

2. Appointment Status
   - Real-time status updates on each appointment (e.g., pending, approved, declined, completed).

3. Document Request Status
   - Current status of each document request indicating whether it is pending, processing, ready for release, or completed.

4. SMS Notifications
   - Automated text messages sent to students informing them of their document availability and appointment updates.

5. Generated Reports
   - Comprehensive reports generated by the system for administrative use, including:
     - Pending Documents
     - Processing Documents
     - Ready for Release Documents
     - Completed Documents
     - Student Records

These outputs improve the efficiency, transparency, accessibility, and overall quality of registrar services at Ilocos Sur Polytechnic State College – Tagudin Campus.
